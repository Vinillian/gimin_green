# 🌾 Wheat Farm Simulator

A browser-based wheat microgreens farm simulator with spatial workflow zones.

## Features
- **4 growth stages**: Soak → Air → Sow → Press → Light
- **Spatial zones**: Buckets, sowing table, pressing shelves, light pallets
- **Resource management**: Water, solution, seeds with per-action costs
- **Real-time game clock**: 1 game day = 60 seconds
- **Visual indicators**: Progress bars, spray/water/transition warnings
- **LocalStorage persistence**: State saved automatically

## How to Run
Open `index.html` in any modern browser.

## Controls
- Click containers or buckets to select
- Use sidebar buttons to perform actions on selected items
- Monitor resources and day counter at the top

## Tech
Vanilla JavaScript, HTML, CSS — no frameworks, no build step.
